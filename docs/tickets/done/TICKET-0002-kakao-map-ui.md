## 목적과 사용자 가치

검색된 장소의 위치를 실제 지도와 목록에서 함께 비교할 수 있게 해, 사용자가 추천 결과의 거리와 동선을 빠르게 파악하도록 한다.

## 구현 범위

- 현재 지도 placeholder를 카카오 지도 SDK 기반의 실제 지도 영역으로 교체
- `/api/search`가 반환한 전체 장소를 지도 마커와 목록에 동일하게 표시
- 추천 순위와 장소 목록을 지도 마커에서 식별할 수 있게 연결
- 검색 결과 좌표에 맞춘 지도 중심·표시 범위 조정
- 지도 로딩 실패, SDK 키 누락, 빈 결과에서도 장소 목록을 계속 사용할 수 있는 fallback 제공
- 320px 모바일부터 데스크톱까지 지도와 목록을 가로 스크롤 없이 사용할 수 있는 반응형 레이아웃 유지
- 키보드 사용자와 화면 읽기 사용자를 위해 지도 밖의 동등한 장소 목록과 보이는 focus 상태 유지
- 클라이언트용 카카오 JavaScript 키 설정 방법과 허용 도메인 설정을 README 및 예시 환경 파일에 문서화
- 지도 렌더링 경계와 검색 결과 반영 동작에 대한 자동 테스트 추가

## 제외 범위

- OpenAI 추천 순위·추천 이유 생성
- 주차장·지하철 경로를 위한 추가 외부 API 호출
- 회원가입, 로그인, D1과 사용자 취향 영구 저장
- 지도 내 장소 상세 패널, 길찾기, 현재 위치 권한 사용
- 카카오 외 지도 공급자 추가
- Cloudflare 프로덕션 배포, 실제 키 등록과 카카오 앱 허용 도메인 변경

## 기술적 접근

- 지도 SDK 로딩과 지도 인스턴스 관리를 별도 어댑터로 분리해 UI와 테스트가 전역 Kakao 객체에 직접 결합되지 않게 한다.
- 검색 API의 정규화된 좌표만 클라이언트에 전달하고 REST API 키는 계속 Worker에만 둔다.
- 공개용 JavaScript 키는 빌드 환경 변수로 주입하되 예시 값만 저장소에 포함하고, 키의 성격과 허용 도메인 제한을 문서화한다.
- 지도 SDK가 없거나 초기화에 실패하면 오류 상태를 지도 영역에 표시하고 기존 장소 목록은 그대로 렌더링한다.
- 마커의 시각 정보만으로 순위나 장소 대응 관계를 전달하지 않는다.

## 비용 영향

- 검색당 기존 카카오 Local REST 호출 수는 늘리지 않는다.
- 지도 표시로 카카오 지도 SDK 사용량이 추가되므로 구현 직전에 공식 쿼터와 이용 조건을 확인한다.
- 유료 기능 활성화, 별도 Cloudflare 제품 또는 새 런타임 의존성은 추가하지 않는다.

## 보안·개인정보 영향

- 카카오 REST API 키는 기존처럼 Worker secret으로만 유지하며 클라이언트에 노출하지 않는다.
- 클라이언트용 JavaScript 키는 공개 식별자라는 전제에서도 카카오 콘솔의 허용 도메인을 최소 범위로 제한하도록 안내한다.
- 현재 위치 권한이나 새로운 사용자 개인정보를 수집하지 않는다.
- 장소 검색어와 좌표 외의 사용자 취향 원문을 지도 SDK에 전달하지 않는다.
