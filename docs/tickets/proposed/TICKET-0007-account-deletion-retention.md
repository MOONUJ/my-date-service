## 목적과 사용자 가치

로그인한 사용자가 서비스 안에서 자신의 계정과 식별 가능한 저장 데이터를 안전하게 삭제할 수 있게 하고, 현재 저장되는 개인정보별 보존 기간을 명확히 문서화한다.

## 구현 범위

- 인증된 사용자의 현재 비밀번호와 명시적 확인값을 다시 검증하는 `DELETE /api/account` 구현
- 교차 출처 요청, 잘못된 비밀번호, 잘못된 확인값과 비로그인 요청을 안전한 오류 코드로 거부
- 성공 시 `users` 행을 삭제하고 외래 키 cascade로 해당 사용자의 모든 세션, 취향, AI 추천 캐시와 일별 AI 사용량을 함께 삭제
- 삭제 응답에서 세션 쿠키를 즉시 만료하고 클라이언트의 사용자·취향·검색 결과 상태를 초기화
- 취향 설정 화면에 계정 삭제 진입점과 별도 확인 dialog를 추가하되 실수로 실행하기 어려운 시각적·키보드 흐름 제공
- 사용자 데이터는 계정 존속 중에만 보관하고, 추천 캐시는 최대 24시간, 세션은 인증 유효기간 7일을 적용한다는 정책 문서화
- 사용자 식별자가 없는 서비스 월별 AI 호출·토큰 집계는 비용 통제를 위한 익명 집계로 유지한다는 점을 명시
- 만료된 세션과 AI 캐시를 정상 요청 중 제한적으로 정리해 만료 데이터가 활성 DB에 불필요하게 남지 않게 함
- 삭제 정상 흐름, 재인증 실패, CSRF, 사용자 격리, cascade와 UI 상태 초기화 테스트

## 제외 범위

- 삭제 유예 기간, 계정 복구, 이메일 확인 링크와 관리자 복구 도구
- 데이터 내보내기, 검색·추천 장기 기록과 감사 로그
- Cloudflare 계정 수준 백업·Time Travel의 물리 삭제 보장 또는 별도 백업 시스템
- 다른 사용자의 계정을 관리하는 관리자 API
- 프로덕션 배포, 원격 D1 변경과 개인정보 처리방침 법률 검토
- ChatGPT/Codex OAuth와 사용자별 외부 모델 계정 연결

## 기술적 접근

- 기존 세션 쿠키 인증과 same-origin 검사를 재사용하고 삭제 직전에 현재 비밀번호를 PBKDF2 경계에서 다시 검증한다.
- 요청 본문은 `{ password, confirmation: "계정 삭제" }`로 제한하고 기존 인증 본문 크기 상한을 적용한다.
- 사용자 ID는 요청 본문에서 받지 않고 인증 세션에서만 결정한다.
- D1의 `ON DELETE CASCADE`가 실제 활성화됐는지 migration과 통합 테스트에서 검증하고, 사용자 삭제 한 번으로 식별 가능한 종속 데이터를 제거한다.
- 익명 월별 사용량은 사용자 ID, 이메일, 취향, 검색어를 포함하지 않으므로 계정 삭제 대상에서 제외한다.
- 비밀번호, 취향 원문, 삭제 요청 본문과 삭제된 행은 로그나 별도 감사 테이블에 남기지 않는다.

## 비용 영향

- 새 외부 서비스나 유료 Cloudflare 기능을 추가하지 않는다.
- 계정 삭제는 사용자 행 1건과 cascade된 소수 행을 삭제하며, 만료 데이터 정리는 요청당 삭제량을 제한해 D1 write 사용량 급증을 피한다.
- 개인용 MVP 규모에서는 기존 D1 무료 티어 범위의 미미한 추가 read/write로 예상한다.

## 보안·개인정보 영향

- 계정 삭제는 되돌릴 수 없는 고위험 작업이므로 로그인 상태만으로 실행하지 않고 현재 비밀번호 재인증과 명시적 확인 문구를 모두 요구한다.
- CSRF 방어, 사용자 ID 비수용, 세션 쿠키 즉시 만료와 모든 사용자 세션 cascade 삭제를 적용한다.
- 활성 D1에서는 이메일, 비밀번호 파생값, 취향, 사용자별 캐시와 사용량을 즉시 제거한다.
- Cloudflare가 제공할 수 있는 플랫폼 수준 백업·복구 보존은 애플리케이션 활성 DB 삭제와 별도 경계이므로 프로덕션 공개 전 실제 설정과 공식 정책을 확인해 개인정보 처리방침에 반영해야 한다.
- 삭제 성공 여부로 다른 이메일이나 계정 존재를 추측할 수 없게 인증된 현재 계정에 대해서만 동일한 응답 경계를 사용한다.

## 완료 조건

- [ ] 인증된 사용자가 올바른 현재 비밀번호와 정확한 확인 문구를 제공하면 자신의 계정을 삭제할 수 있다.
- [ ] 삭제 후 기존 세션과 다른 기기의 동일 계정 세션이 모두 보호 API에 접근할 수 없다.
- [ ] 사용자, 취향, 세션, AI 캐시와 사용자 일별 사용량 행은 삭제되고 익명 월별 집계에는 개인정보가 남지 않는다.
- [ ] 잘못된 비밀번호·확인 문구, 비로그인과 교차 출처 요청은 데이터 변경 없이 거부된다.
- [ ] UI가 삭제의 비가역성을 명확히 알리고, 성공 후 인증 화면으로 돌아가며 이전 취향·검색 결과를 표시하지 않는다.
- [ ] 320px 전후 모바일과 데스크톱에서 dialog, 키보드 focus, label과 오류 연결이 동작한다.

## 결정 사항

- 활성 D1의 식별 가능한 계정 데이터는 유예 없이 즉시 hard delete하는 방식을 권장한다. 이 티켓 승인은 복구 불가능한 즉시 삭제 정책 승인이다.
- 삭제 전 현재 비밀번호와 정확한 `계정 삭제` 확인 문구를 모두 요구한다.
- 사용자 식별자가 없는 월별 AI 사용량 집계는 비용 차단선의 정확성을 위해 유지한다. 식별 가능한 삭제 데이터에는 포함하지 않는다.
- 플랫폼 백업의 물리적 보존 보장은 이번 구현 범위에서 제외하고, 공개 배포 전 Cloudflare 설정·정책 확인과 개인정보 처리방침 반영을 별도 필수 작업으로 둔다.
